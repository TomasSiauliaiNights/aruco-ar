Print a marker

ArUco 4x4_50 — the dictionary this app detects. The size you print at must match the size the app is told about, or every distance it reports is wrong by the same factor.

Printing it without scaling

  • In the print dialog set Scale to 100%. Do not use “Fit to page”, “Shrink to printable area” or “Scale to fit” — each of those silently resizes the marker.
  • On macOS Preview and Safari, make sure Scale: 100% is selected rather than “Scale to Fit”.
  • Then measure the printed black square with a ruler, outer edge to outer edge. If it is not the size you asked for, type the measured value into the app’s debug panel instead of trusting the setting.
  • Print on matte paper if you can. Glossy paper and lamination produce specular highlights that wash out the border and cost you detections.
  • Mount it flat. A curled or bent marker breaks the planarity the pose solver assumes, and shows up as a model that leans.

Calibration boards

For per-device camera calibration, the calibration page generates its own printable board.
