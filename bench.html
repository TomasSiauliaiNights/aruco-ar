Benchmark

Runs the real detector over a synthetic clip of a moving marker, at several processing widths. This measures detection on this device, which is the only number that matters — desktop figures are not predictive of a phone.

The clip is generated here, so there is no camera and no network involved beyond loading the detector itself.

Render-rate check

Detection time is only half the story: the app renders on the main thread while the worker detects. This measures the frame rate actually achieved with both running.
